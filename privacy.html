Ditto privacy policy

Last updated 23 September 2026.

Who runs Ditto

Ditto is a personal tool run by one person, Mike Papper, on his own computer, for mailboxes he owns or that their owners have handed to him to organize. Contact: bodaro@gmail.com.

What data Ditto reads

Ditto reads mail headers (sender, subject, date, mailing-list identifiers), message text, and folder or label names in the connected mailbox. For a Google account it also reads calendar events and contacts of that account. It reads this data to decide which folder a message belongs in and whether a message is junk or marketing.

What Ditto does with it

  • It moves messages between folders and labels, and creates or updates mail filters, in the connected mailbox only.
  • It keeps a small record of its own decisions (sender, subject, chosen folder) on the owner's computer so that a decision can be undone and so that it does not repeat a question.
  • To classify a message it may send that message's sender, subject and an excerpt of its text to an AI model provider (Anthropic) under that provider's API terms. Those excerpts are used only to produce the classification and are not used to train models.

What Ditto does not do

  • It does not sell, rent, or share mailbox data with anyone.
  • It does not use mailbox data for advertising.
  • It does not let any person other than the mailbox owner and the operator read the mail.
  • It does not transfer data to any server the operator does not control, except the AI classification calls described above.

Google user data

Ditto's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Ditto's own records stay on the operator's computer. Access is removed at any time by revoking Ditto in the Google account's third-party access settings; the operator then deletes the local records on request.
