Ditto

Ditto is a personal mail-organizing tool. It runs on its owner's own computer and works on the owner's own mailboxes. It is not a public service and it has no other users.

What it does

Ditto watches a mailbox and files mail the way its owner already files mail by hand. The owner moves a message into a folder; Ditto learns from that move and files later mail from the same sender the same way. It also sets junk and marketing mail aside in holding folders so the owner can review it.

Google account access

For a Gmail account, Ditto uses Google's OAuth sign-in and asks for permission to read and label mail, to manage mail filters, and to read the calendar and contacts of the same account. It uses this access only to organize that account's own mail.
